### 3.1 `E4(g)` — Smart-Pointer & Primitive Slice Serialization (`44ee835`)

### 3.2 `E4` / `E3.1` — `RankSelectInterleaved256` Unpadded 40-Byte `InterleavedLine` & `select0_cache` (`7dd5bd9`)

### 3.3 `E4` / `E3.2` — Exact Bit-Offset `select1` / `select0` Samples & Rank-Free `next_geq` in `EliasFano` (`b6cbccc`)

### 3.4 `E4(e)` / `E3.3` — Top-Down Bulk `DoubleArrayTrie::build_from_sorted` & $O(\text{degree})$ `ZiporaTrie` Child Links (`21d6e06`)
- **Files**: `src/fsa/double_array/trie.rs`, `src/fsa/zipora_trie/{builder,search,storage,trie}.rs`

### 3.5 `E4(b)` / `E3.4` — SwissTable 16-Way SSE2 Group Probing & `17 B/slot` Layout in `ZiporaHashMap` (`f1cd7c0`)

### 3.6 `E4(f)` / `E3.5` — $O(1)$ Size-Class LUT & Per-Thread Magazine in `LockFreeMemoryPool` (`48d5a5a`, `S49-R1..R5`, `S50-R1`)
- **Files**: `src/memory/lockfree_pool.rs`
- **Root Cause**: Every `allocate(256)` + `deallocate(ptr, 256)` pair scanned `SIZE_CLASSES` linearly and executed 4 atomic RMW `lock` operations (`2 x lock cmpxchgq` on `bin.head` + `2 x lock xaddq` on `bin.count`, plus atomic stats).
- **Optimization & `S49-R1..R4` + `S50-R1` Soundness Hardening**: Added `SIZE_CLASS_LUT: [u8; SIZE_CLASS_LUT_LEN]` (`SIZE_CLASS_LUT_LEN = (FAST_BIN_THRESHOLD / ALIGN_SIZE) + 1` for `size <= 4096`, plus `next_power_of_two().trailing_zeros()` for `4097..=65536`) in `find_fast_bin` and a per-thread magazine (`FastBinMagazine` in `FAST_BIN_MAGAZINE` backed by `ThreadMagazine` in `MAGAZINE_OWNER_GUARD`, caching up to `MAGAZINE_CAP = 16` `u32` block offsets per bin for the active `pool_id` assigned by `NEXT_LOCKFREE_POOL_ID`, via `allocate`, `allocate_from_fast_bin_index`, `deallocate`, and `PoolArena::push_free_fast_bin_offset` with shared `Arc<PoolArena>` / `Weak<PoolArena>` and `Weak<ThreadMagazine>` lifecycle tracking [`S47-R4`, `S48-R2`, `S48-R4`]). In `S49-R1..R4` and `S50-R1`, hardened the magazine against five concurrency/lifecycle edge cases:
  1. **`S49-R1` (Cross-Pool Stale Registration)**: Tagged `ThreadMagazine` with `pool_id: u64`; on pool switch, `FastBinMagazine::pop` and `FastBinMagazine::push` drain the previous pool's magazine, remove its `Weak<ThreadMagazine>` from the old `PoolArena::magazines`, and register a fresh `Arc<ThreadMagazine>` with the new `pool_id` (verified by `mag.pool_id == self.pool_id` in `drain_all_magazines`; `test_s49_r1_cross_pool_stale_registration_no_duplicate_blocks`).
  2. **`S49-R2` (Owner `pop` vs `drain_all_magazines` Steal Race)**: Replaced the non-atomic `slot.load(Relaxed)` + `slot.store(0, Release)` in `FastBinMagazine::pop` with a single atomic `slot.swap(0, Ordering::AcqRel)` matching `ThreadMagazine::drain_into_arena` (`test_s49_r2_owner_pop_vs_steal_no_duplicate_blocks`), and removed the dead steal-mode flag (`S49-R10`).
  3. **`S49-R3` (Cross-Thread Fast-Bin Double-Free Rejection)**: Transitioned the fast-bin header tag from `FAST_BIN_LIVE_TAG | bin` to `FAST_BIN_FREE_TAG | bin` via `compare_exchange` in `transition_fast_bin_live_to_free` **before** caching a block in the thread-local magazine (and restored `FAST_BIN_LIVE_TAG | bin` in `mark_fast_bin_live` upon magazine pop), so a concurrent double-free from another thread while the block resides in the first thread's magazine is rejected (`test_s49_r3_cross_thread_fast_bin_double_free_rejected`).
  4. **`S49-R4` ($O(1)$ Clean-Magazine Skip on Exhausted Pool)**: Added `dirty_magazines: AtomicUsize` on `PoolArena` and `non_empty_bins: AtomicU64` bitmask on `ThreadMagazine` so `drain_all_magazines` returns `0` immediately via a single `Acquire` load (`~19 ns`) without locking `magazines: Mutex<...>` or scanning `16 x 16` slots across 512 idle threads when no blocks are cached (`test_s49_r4_exhausted_pool_failing_allocate_skips_clean_magazines`).
  5. **`S50-R1` (Push-vs-Drain Store-Buffering & Wraparound Slot Check)**: Unified dirty-magazine tracking into `ThreadMagazine::non_empty_bins` (`prev == 0` on `shared.non_empty_bins.fetch_or(bit, Ordering::AcqRel)` increments `arena.dirty_magazines.fetch_add(1, Ordering::AcqRel)`, paired with `self.non_empty_bins.swap(0, Ordering::AcqRel) != 0` decrementing `arena.dirty_magazines` in `drain_into_arena` and `unregister_magazine`) and made `FastBinMagazine::push` skip any non-zero slots on `c == MAGAZINE_CAP` wraparound (`while c < MAGAZINE_CAP { if shared.slots[bin][c].load(Ordering::Acquire) == 0 { ... } }`), preventing store-buffering from stranding a newly pushed block when a concurrent `drain_into_arena` clears `non_empty_bins` (`test_s50_r1_push_vs_drain_store_buffering_no_lost_blocks`, `0/64` Miri seeds) or overwriting undrained slots (`test_s50_r1_push_does_not_overwrite_undrained_slots`).
- **Measured Result & `S49-R5` / `S50-R1` / `S50-R3` Latency Trade-Off Disclosure**:
  - At `1cb20d8` (using non-atomic `Cell<u32>` slot reads/writes without cross-thread steal or double-free CAS), `alloc_free_1t` ran at `5.996 ns/op` (`core_bench` `5.986 ns/op`) and `alloc_free_4t` ran at `6.226 ns/op` (`core_bench` `6.244 ns/op`).
