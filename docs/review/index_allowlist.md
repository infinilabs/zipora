# Decoder Direct Indexing Allowlist and Justifications (Rule D10.1)

This document inventories all direct slice indexing sites (`data[i]`, `bytes[..]`, `buf[..]`, etc.)
in decoder paths across `entropy/`, `compression/`, `blob_store/`, `io/var_int*.rs`, and `succinct/*/` load paths.

**Rule D10.1 / Agreement 12 Requirement:**
- Decoders taking untrusted bytes must return `Err`, never panic on malformed input.
- Direct indexing must be replaced by `.get(..).ok_or(..)` or guarded by a bounds proof at the loop header.
- Each site in this allowlist is tracked by `scripts/index_audit.py` with exact per-subsystem ratchet ceilings.
- During Phase C review sessions (C1, C2, C5), reviewers must eliminate these sites or document proofs.
